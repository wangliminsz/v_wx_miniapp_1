The @payloadcms/plugin-search plugin creates a special collection (usually called search or search-results) that contains indexed copies of documents from all enabled collections (posts, vendure-product, etc.).
You should query this collection — not query posts and vendure-product separately.
1. Most common API endpoints
Payload exposes REST and GraphQL — both work perfectly from Vue.
REST (easiest to start with)
textGET  /api/search
     ?where[title][like]=ponatinib
     &limit=20
     &page=1
     &sort=-priority   (or -createdAt, title, etc.)
     &depth=1          (important if you want the full linked doc)
Example full URL:
texthttps://your-site.com/api/search?where[title][like]=普纳替尼&limit=12&depth=1&sort=-priority
GraphQL (more powerful / flexible)
graphqlquery SearchProductsAndPosts($searchTerm: String!) {
  Search(
    where: { title: { like: $searchTerm } }
    limit: 20
    sort: "-priority"
  ) {
    docs {
      id
      title
      priority
      excerpt         # if you indexed it
      createdAt
      updatedAt

      # This is the most important field
      doc {
        relationTo    # ← "posts" or "vendure-product"
        value {       # ← the actual linked document (with depth=1)
          ... on VendureProduct {
            id
            name
            slug
            richDescription
            heroImage {
              url
            }
            # ... any other fields you need
          }
          ... on Post {
            id
            title
            slug
            content
          }
        }
      }
    }
    totalDocs
    totalPages
    page
  }
}
2. Recommended Vue 3 + Axios / Fetch example
vue<!-- SearchResults.vue -->
<script setup>
import { ref, watch } from 'vue'
import { useRoute, useRouter } from 'vue-router'
import axios from 'axios'

const route = useRoute()
const router = useRouter()

const searchTerm = ref(route.query.q || '')
const results = ref([])
const loading = ref(false)
const total = ref(0)

const PAYLOAD_URL = import.meta.env.VITE_PAYLOAD_URL || 'http://localhost:3000'

async function doSearch() {
  if (!searchTerm.value.trim()) {
    results.value = []
    total.value = 0
    return
  }

  loading.value = true

  try {
    const res = await axios.get(`${PAYLOAD_URL}/api/search`, {
      params: {
        where: {
          title: {
            like: searchTerm.value,
          },
          // optional: only products
          // 'doc.relationTo': { equals: 'vendure-product' },
        },
        limit: 20,
        page: 1,
        depth: 1,
        sort: '-priority',        // higher priority first
        // or sort: 'title'       // alphabetical
      },
    })

    results.value = res.data.docs
    total.value = res.data.totalDocs
  } catch (err) {
    console.error('Search failed', err)
    results.value = []
  } finally {
    loading.value = false
  }
}

// Auto search when query changes (debounce in real app)
watch(
  () => route.query.q,
  (newQ) => {
    searchTerm.value = newQ
    doSearch()
  },
  { immediate: true }
)

// Optional: update URL when user types
function updateSearch() {
  router.push({ query: { q: searchTerm.value } })
}
</script>

<template>
  <div class="search-page">
    <input
      v-model="searchTerm"
      @input="updateSearch"
      placeholder="搜索产品或文章..."
      class="search-input"
    />

    <div v-if="loading">加载中...</div>

    <div v-else-if="results.length === 0 && searchTerm">
      未找到匹配结果
    </div>

    <ul v-else class="results">
      <li v-for="item in results" :key="item.id" class="result-item">
        <span class="type-badge">
          {{ item.doc.relationTo === 'vendure-product' ? '产品' : '文章' }}
        </span>

        <h3>
          <router-link
            :to="
              item.doc.relationTo === 'vendure-product'
                ? `/products/${item.doc.value.slug}`
                : `/posts/${item.doc.value.slug}`
            "
          >
            {{ item.title || item.doc.value.name || '无标题' }}
          </router-link>
        </h3>

        <p v-if="item.excerpt" class="excerpt">{{ item.excerpt }}</p>

        <!-- Product specific -->
        <img
          v-if="item.doc.relationTo === 'vendure-product' && item.doc.value.heroImage?.url"
          :src="item.doc.value.heroImage.url"
          alt="product image"
          width="120"
        />
      </li>
    </ul>
  </div>
</template>

4. Tips & Next Steps

Environment variable
Put your Payload URL in .env → VITE_PAYLOAD_URL=https://your-domain.com
Authentication
If your search collection is not public, send JWT in headers:JavaScriptaxios.get(..., {
  headers: { Authorization: `Bearer ${token}` }
})
Debounce the search input (lodash.debounce or custom timeout) to avoid too many requests.
